# 👋 Привет! Меня зовут Дарья.

Я — Java-разработчик и преподаватель программирования с фокусом на создании надежных веб-приложений и автоматизации тестирования. Мне нравится не только писать чистый код, но и помогать другим разбираться в сложных концепциях программирования.

- 🔭 **В разработке** я специализируюсь на создании бэкенда для веб-приложений, особенно интересуюсь сферой Fintech (банки, биржи).
- 🌱 **В преподавании** моя цель — объяснять сложные темы простым и понятным языком, подкрепляя теорию практическими задачами.
- 👨‍💻 **В тестировании** я применяю инженерный подход для обеспечения качества кода и автоматизации рутинных проверок.
